这个站点用来记录一些思考、随手记和长文。

- 「说说」是短动态，想到什么发什么。
- 「文章」是写完整的内容。

## 怎么用

```bash
# 上传图片，markdown 链接自动进剪贴板
./upload.sh ~/Desktop/截图.png

# 编辑 content/memos/001.md 写微博（新内容写在文件最前面）
# 编辑 content/posts/*.md 写文章

# 构建并上线
./deploy.sh
```

代码块右上角有复制按钮，点一下就能拿走代码。
